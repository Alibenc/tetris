# Создаём AI-агента в n8n с нуля

**Цель:** создать веб-чат по ссылке, где AI-помощник общается в заданном стиле, помнит контекст и умеет пользоваться калькулятором. Без MAX, Telegram и VK.

**Для кого:** преподаватель и ученики 11–14 лет. **Время занятия:** 60 минут, если аккаунт n8n и доступ к модели подготовлены заранее.

> Интерфейс n8n обновляется: названия и расположение некоторых кнопок могут отличаться. Важны названия узлов и их функции.

## 0. Что подготовить заранее (преподавателю)

1. Рабочий аккаунт n8n Cloud (на скриншоте уже открыт). Пробный период ограничен; после него для постоянной работы потребуется тариф или самостоятельный хостинг.
2. API-ключ провайдера LLM, совместимого с n8n (например, OpenAI API). **Подписка ChatGPT Plus не включает оплату API**. У провайдера должен быть доступный баланс/квота.
3. Не показывайте ключ ученикам и не вставляйте его в промпт, сайт или публичную ссылку.
4. Для публичного чата предусмотрите ограничение доступа, расходов и тестирование содержания ответов. Не просите учеников вводить личные данные.

## 1. Создаём workflow (5 минут)

1. В левом верхнем углу нажмите **+ → New workflow**. Не выбирайте **New agent**: для обучения собираем цепочку вручную.
2. Назовите workflow `Пиксель — AI-помощник`.
3. Нажмите **Save**, если кнопка доступна.

## 2. Добавляем чат (5 минут)

1. Нажмите **Add first step** (или большой `+`).
2. В поиске введите `Chat Trigger` или `When chat message received`.
3. Выберите узел. Это точка входа: каждое новое сообщение запускает workflow.
4. Пока оставьте стандартные настройки. Для первого теста используем встроенный тестовый чат редактора.

## 3. Подключаем AI Agent (5 минут)

1. Нажмите `+` справа от Chat Trigger.
2. Найдите **AI Agent** и добавьте.
3. Убедитесь, что есть соединение **Chat Trigger → AI Agent**.
4. В AI Agent установите источник сообщения `Connected Chat Trigger Node`, если эта опция есть. Если требуется вручную указать текст сообщения, используйте выражение `{{ $json.chatInput }}`.

## 4. Подключаем нейросеть (10 минут)

1. Под блоком AI Agent найдите разъём **Chat Model** и нажмите `+`.
2. Выберите **OpenAI Chat Model** (или модель другого подключённого провайдера).
3. В поле **Credential** выберите **Create new credential**.
4. Вставьте **API key** провайдера и сохраните подключение. Делайте это без демонстрации ключа на проекторе.
5. Выберите доступную модель, поддерживающую tool calling. Для первого занятия предпочтительна недорогая модель.
6. Вернитесь к AI Agent.

**Если ошибка 401:** проверьте API-ключ. **Если 429:** проверьте квоту, баланс, ограничения скорости запросов.

## 5. Задаём характер и правила (10 минут)

1. Откройте узел **AI Agent**.
2. Найдите **Options → Add Option → System Message** (или поле `System Message`, если уже отображается).
3. Вставьте промпт ниже.

```text
Ты — Пиксель, дружелюбный AI-помощник для школьников 11–14 лет.

СТИЛЬ:
- Общайся на «ты», по-русски, понятно и доброжелательно.
- Пиши обычно 2–5 предложений, если не требуется подробное объяснение.
- Иногда используй лёгкий юмор, но без мата и оскорблений.
- Не начинай каждый ответ с приветствия.

ОБУЧЕНИЕ:
- Если спрашивают о программировании, объясняй на простых примерах.
- Если просят решить учебную задачу, сначала дай подсказку; полное решение — по дополнительной просьбе.
- Если ученик ошибся, объясни ошибку спокойно.
- Если вопрос непонятен, задай один уточняющий вопрос.
- Для точных вычислений используй Calculator, если он подключён.

СПЕЦИАЛЬНЫЕ СЦЕНАРИИ:
- На вопрос «Кто тебя создал?» отвечай: «Меня собрали ученики на занятиях по AI. Вот такие у меня крутые создатели 😎».
- На «Мне скучно» предложи небольшую загадку по программированию.
- На «Я ничего не понимаю» объясни тему ещё проще, через бытовую аналогию.

ОГРАНИЧЕНИЯ:
- Не запрашивай адреса, телефоны, пароли и другие личные данные.
- Не притворяйся человеком.
- Не выдумывай факты и результаты инструментов.
- Если не знаешь ответа, честно скажи об этом.
- Не помогай с опасными или незаконными действиями.
```

> Важно: системный промпт **не гарантирует** строгого соблюдения всех правил. Для обязательных фиксированных ответов и запретов нужны отдельные узлы и проверки.

## 6. Первый тест (5 минут)

1. Нажмите **Open chat** / **Chat** в редакторе (в зависимости от версии).
2. Напишите `Привет! Кто тебя создал?`.
3. Проверьте, что агент отвечает в заданном стиле.
4. Спросите `Объясни, что такое переменная в Python`.
5. Если ответа нет, проверьте подключение Chat Model и сообщение об ошибке у узла.

## 7. Подключаем калькулятор (5 минут)

1. Под AI Agent найдите разъём **Tool** и нажмите `+`.
2. Выберите **Calculator**.
3. Отправьте сообщение: `Посчитай (125 * 37 + 875) / 5. Используй калькулятор.`
4. Правильный ответ: **1100**.
5. Откройте детали выполнения и покажите ученикам, что модель вызвала отдельный инструмент.

## 8. Добавляем память (5 минут)

1. Под AI Agent найдите разъём **Memory** → `+` → **Simple Memory**.
2. Для `Session ID` используйте идентификатор сессии из Chat Trigger (обычно доступен вариант **Connected Chat Trigger Node**).
3. Установите `Context Window Length` равным `5` для демонстрации.
4. В **одной и той же сессии чата** отправьте: `Мой любимый предмет — информатика`.
5. Следом спросите: `Какой мой любимый предмет?`.
6. Если агент не помнит, проверьте Session ID и то, что сессия не сменилась.

**Важное ограничение:** Simple Memory подходит для учебного примера, но не является надёжным долговременным хранилищем для производственного многопользовательского сервиса.

## 9. Делаем чат доступным по ссылке (5 минут)

1. Откройте настройки **Chat Trigger**.
2. Найдите переключатель **Make Chat Publicly Available** и включите его.
3. Выберите **Hosted Chat** (если интерфейс предлагает режимы Hosted/Embedded).
4. При необходимости настройте заголовок, приветствие и доступные параметры внешнего вида.
5. **Сохраните и опубликуйте/активируйте workflow** — конкретная кнопка зависит от версии n8n.
6. Скопируйте **production chat URL** из Chat Trigger и откройте в режиме инкогнито.
7. Проверьте, что агент отвечает вне редактора.

**Осторожно:** любой, кто получит публичную ссылку, потенциально сможет отправлять запросы и расходовать API-квоту. Для урока лучше не публиковать ссылку в открытом интернете, контролировать использование и после занятия отключить публичный доступ, если он больше не нужен.

## 10. Самостоятельное задание для учеников

Поменяйте системный промпт так, чтобы получился один из персонажей:

- **Математик** — объясняет решения и даёт подсказки.
- **Наставник Python** — объясняет код простыми словами.
- **Ведущий викторины** — задаёт по одному вопросу и проверяет ответ.
- **Помощник по английскому** — предлагает короткие упражнения.

Проверьте три сценария: обычный вопрос, специальная фраза и вопрос с вычислением. Запишите, что получилось не так, и улучшите промпт.

## 11. Как сделать строго фиксированные ответы

Если ответ **обязательно** должен быть одинаковым, не полагайтесь только на System Message.

1. После Chat Trigger добавьте **Switch**.
2. Проверяйте текст сообщения, например `{{ $json.chatInput }}`.
3. Для команды `/help` направьте выполнение в **Edit Fields (Set)**, который создаёт поле `text` с нужным ответом.
4. Для остальных сообщений оставьте ветку на AI Agent.
5. Для чат-ответа убедитесь, что ветки возвращают поле `text` или `output` в формате, который ожидает ваш Chat Trigger; при необходимости добавьте **Respond to Chat** и явно передайте текст ответа.
6. Протестируйте обе ветки в тестовом и опубликованном чате.

Пример фиксированного текста: `Команды: /help — помощь. Спроси меня о Python или математике!`

## 12. Типичные ошибки

| Симптом | Возможная причина | Что проверить |
|---|---|---|
| `No chat model connected` | Не подключена модель | Разъём Chat Model под AI Agent |
| `401 Unauthorized` | Неверный API-ключ | Credentials провайдера |
| `429 Too Many Requests` | Лимиты или баланс | Квоты и биллинг API |
| Нет ответа в публичном чате | Workflow не опубликован | Статус workflow и production URL |
| Не помнит прошлое сообщение | Нет памяти или новый Session ID | Simple Memory и идентификатор сессии |
| Не вызывает калькулятор | Инструмент не подключён или не выбран моделью | Tool, промпт, журнал выполнения |
| Публичная ссылка не открывается | Неправильный URL или настройки публикации | URL в Chat Trigger и доступность Cloud |

## 13. Итоговая схема

```text
Chat Trigger ────────────> AI Agent ────────────> Ответ в веб-чате
                              │
                              ├── Chat Model (LLM)
                              ├── Simple Memory
                              └── Calculator (Tool)
```

Ученик должен уметь объяснить, что запускает workflow, где находятся инструкции, зачем нужны память и инструмент, и как изменить характер агента.
