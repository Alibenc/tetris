# Практические задания по React + TypeScript

**Стек:** React, TypeScript, Ant Design, Tailwind CSS.  
**Формат:** самостоятельная практика. Готовый код не даётся: нужно продумать состояния, компоненты и обработчики.

## 1. Генератор случайных чисел

**Сложность:** 1/10  
**Практика:** `useState`, `onClick`.

Создай приложение, которое по кнопке генерирует случайное число от 1 до 100 и показывает его на экране.

**Дополнительно:** поля для задания минимального и максимального значений; история последних пяти чисел.

## 2. Корзина интернет-магазина

**Сложность:** 4/10  
**Практика:** массивы в состоянии, `props`, обработчики событий.

Подготовь массив из 4–5 товаров с названием и ценой. Покажи товары карточками. Пользователь должен уметь добавлять их в корзину, изменять количество и удалять позиции. Выводи общую стоимость покупки.

**Дополнительно:** кнопка «Очистить корзину»; сообщение о пустой корзине.

## 3. Таймер обратного отсчёта

**Сложность:** 4/10  
**Практика:** `useState`, `useEffect`, `setInterval` и очистка интервала.

Пользователь задаёт время в секундах и запускает обратный отсчёт. Реализуй кнопки «Старт», «Пауза», «Сброс». Таймер должен останавливаться на нуле.

**Дополнительно:** отображение времени в формате `мм:сс`.

## 4. Конвертер валют

**Сложность:** 3/10  
**Практика:** управляемые поля ввода, состояния, вычисления.

Создай конвертер между тремя валютами. Пользователь вводит сумму и выбирает исходную и целевую валюты; результат пересчитывается автоматически.

Для начала используй фиксированные курсы в объекте, без API.

**Дополнительно:** кнопка, меняющая валюты местами.

## 5. Каталог фильмов

**Сложность:** 4/10  
**Практика:** `fetch`, `useEffect`, загрузка, ошибки, фильтрация.

Получи список фильмов из доступного API или локального JSON-файла. Покажи карточки с названием, годом и описанием (если эти поля есть в данных). Добавь поиск по названию.

**Дополнительно:** фильтр по году или жанру, если такие данные доступны.

## 6. Игра «Угадай число»

**Сложность:** 2/10  
**Практика:** `useState`, события, условный рендеринг.

Приложение загадывает число от 1 до 100. Пользователь вводит догадку, а приложение отвечает: «Больше», «Меньше» или «Угадал». Показывай количество попыток.

**Дополнительно:** кнопка «Новая игра» и ограничение числа попыток.

## 7. Редактор профиля

**Сложность:** 3/10  
**Практика:** формы, `useState`, `props`.

Сделай форму с именем, возрастом и описанием. После нажатия «Сохранить» данные отображаются в карточке профиля. Изменения в полях не должны менять сохранённую карточку до повторного нажатия кнопки.

**Дополнительно:** проверка пустого имени и кнопка «Редактировать».

## 8. Система уведомлений

**Сложность:** 4/10  
**Практика:** массивы в состоянии, уникальные идентификаторы, события.

Добавь кнопки создания уведомлений разных типов: успех, предупреждение и ошибка. Уведомления появляются списком, каждое можно закрыть.

**Дополнительно:** автоматическое исчезновение через несколько секунд с корректной очисткой таймеров.

## 9. Мини-библиотека книг

**Сложность:** 4/10  
**Практика:** компоненты, `map`, `filter`, `props`, состояние.

Создай массив книг: название, автор, жанр. Отобрази карточки книг. Реализуй поиск по названию, фильтр по жанру и добавление в избранное.

**Дополнительно:** отдельная вкладка «Избранное».

## 10. Трекер привычек

**Сложность:** 5/10  
**Практика:** массив объектов, обновление состояния, `localStorage`.

Пользователь добавляет привычки (например, чтение, зарядка) и отмечает выполненные за сегодня. Показывай число выполненных привычек и общий прогресс.

**Дополнительно:** сохранение списка в `localStorage`, возможность удаления привычки.

---

## Рекомендуемый порядок выполнения

1. **Угадай число** — события, состояние и условный рендеринг.
2. **Редактор профиля** — несколько состояний и управляемые поля.
3. **Корзина магазина** — массивы, `props`, пересчёт суммы.
4. **Таймер** — эффекты и очистка интервала.
5. **Каталог фильмов** — запросы, обработка загрузки и ошибок.

**Общее правило:** сначала реализуй функциональность в `App.tsx`, затем выдели повторяющиеся или самостоятельные части в компоненты. Используй TypeScript без `any`. Ant Design — для готовых элементов интерфейса, Tailwind — для компоновки и отступов.
