# Практическая работа по CSS — 10 заданий

**Цель:** научиться оформлять HTML-страницы с помощью CSS.

**Перед началом:** создавай для каждой работы файлы `index.html` и `style.css`. Подключай стили в `<head>`:

```html
<link rel="stylesheet" href="style.css">
```

Пиши CSS в отдельном файле. **Flexbox использовать не нужно.**

## Задание 1. Цветная страница

Создай страницу с заголовком и двумя абзацами.

**Требования:**
- Светло-серый фон страницы.
- Синий заголовок размером `36px`.
- Абзацы размером `18px`.

**Подсказка:** `background-color`, `color`, `font-size`.

## Задание 2. Моя любимая игра

Создай страницу о любимой игре: заголовок, описание и список её особенностей.

**Требования:**
- Измени шрифт всей страницы.
- Выровняй заголовок по центру.
- Выдели описание отдельным цветом через CSS-класс.

**Подсказка:** `font-family`, `text-align`, `.description`.

## Задание 3. Разноцветные блоки

Создай три элемента `<div>` с разным текстом.

**Требования:**
- Каждому блоку назначь отдельный класс и цвет фона.
- Ширина каждого блока — `250px`, высота — `100px`.
- Внутренний отступ — `15px`.

**Подсказка:** `width`, `height`, `padding`, `background-color`.

## Задание 4. Карточка персонажа

Создай карточку игрового персонажа с именем, изображением, описанием и характеристиками.

**Требования:**
- Ширина карточки — `300px`.
- Добавь фон, рамку, закруглённые углы и отступы.
- Оформи имя персонажа отдельно от описания.

**Подсказка:** `border`, `border-radius`, `padding`, `width`.

## Задание 5. Красивая кнопка

Создай кнопку «Начать игру».

**Требования:**
- Синий фон, белый текст, закруглённые углы.
- Добавь внутренние отступы.
- При наведении фон становится темнее, а курсор меняется на указатель.
- Сделай изменение цвета плавным.

**Подсказка:** `button:hover`, `cursor`, `transition`.

## Задание 6. Карточка игрового предмета

Создай карточку меча, брони или другого игрового предмета. Добавь название, изображение, описание, стоимость и редкость предмета.

**Требования:**
- Ширина карточки — `300px`.
- Добавь фон, рамку, отступы и закругления.
- Расположи карточку по центру страницы.
- Выдели стоимость и редкость цветом.

**Подсказка:** `margin: 0 auto`, `padding`, `border`, `border-radius`.

## Задание 7. Меню сайта

Создай меню из четырёх ссылок: «Главная», «Игры», «Новости», «Контакты».

**Требования:**
- Ссылки располагаются друг под другом.
- Убери стандартное подчёркивание.
- Измени цвет ссылок и добавь отступы.
- При наведении цвет ссылки меняется.

**Подсказка:** `display: block`, `text-decoration`, `a:hover`, `margin`.

## Задание 8. Профиль игрока

Создай блок профиля с аватаром, никнеймом, уровнем, количеством побед и кнопкой «Добавить в друзья».

**Требования:**
- Все элементы располагаются вертикально.
- Добавь фон, отступы и закруглённые углы.
- Сделай никнейм заметнее остальных надписей.
- Оформи кнопку и эффект наведения.

**Подсказка:** `background-color`, `padding`, `font-weight`, `:hover`.

## Задание 9. Страница регистрации

Создай форму с полями «Имя», «Email», «Пароль» и кнопкой «Зарегистрироваться».

**Требования:**
- Используй подходящие типы полей: `text`, `email`, `password`.
- Оформи поля: ширина, внутренние отступы, рамки и закругления.
- Расположи поля друг под другом.
- Кнопка меняет цвет при наведении.

**Подсказка:** `input`, `display: block`, `width`, `padding`, `border-radius`, `button:hover`.

## Задание 10. Мини-сайт игровой студии

Создай небольшую страницу игровой студии.

**На странице должны быть:**
- Название студии и короткое описание.
- Изображения трёх игр.
- Название и описание каждой игры.
- Кнопки «Подробнее».
- Блок с контактами внизу страницы.

**Требования:**
- Все основные блоки располагаются вертикально.
- Используй единую цветовую гамму.
- Добавь классы, размеры, отступы, рамки и закругления.
- Сделай эффекты наведения для кнопок.
- Страница должна выглядеть аккуратно и читабельно.

**Подсказка:** используй все изученные темы: селекторы, цвета, шрифты, блочную модель и `:hover`. Flexbox не нужен.
