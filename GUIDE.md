# Визуальная новелла на Pygame — пошаговая инструкция

**Цель:** изучить устройство небольшого игрового движка и самостоятельно расширить его. Мы **не пишем конкретный сюжет**: в проекте только тестовые реплики и два варианта выбора.

**Подготовка:** Python 3.10+, базовые знания функций, словарей, списков и циклов.

## Этап 1. Запускаем проект

1. Распакуйте ZIP в отдельную папку.
2. Откройте её в VS Code или PyCharm.
3. Откройте терминал в корне проекта и выполните:

   ```bash
   python -m pip install -r requirements.txt
   python run.py
   ```

4. Посмотрите на окно: фон, временный персонаж и окно диалога.
5. Нажмите `Пробел`, дождитесь выбора и нажмите одну из кнопок. Попробуйте `R`.

**Проверьте себя:** чем отличается нажатие пробела во время появления текста от нажатия после полного появления?

## Этап 2. Разбираемся с файлами

Откройте эти файлы по порядку:

| Файл | За что отвечает |
| --- | --- |
| `run.py` | Запускает `Game` |
| `novel/settings.py` | Размер окна, FPS, скорость текста, пути |
| `novel/app.py` | Игровой цикл, события и текущая реплика |
| `novel/story.py` | Читает сценарий и проверяет переходы |
| `novel/ui.py` | Рисует текст и кнопки |
| `novel/resources.py` | Загружает изображения, запоминает их в кэше |
| `novel/save.py` | Пишет и читает сохранение |
| `story/demo.json` | Хранит узлы и переходы |

**Задание:** найдите метод `run()` и объясните, зачем нужны `handle_event()`, `draw()` и `clock.tick(FPS)`.

## Этап 3. Меняем оформление без изменения движка

1. Откройте `novel/settings.py`.
2. Поменяйте `TITLE`, `WIDTH`, `HEIGHT` (для начала оставьте 1000×600: некоторые элементы интерфейса пока используют фиксированные отступы).
3. Измените `TEXT_SPEED` с `45` на `15`, затем на `100`.
4. Найдите цвета `PANEL_COLOR` и `ACCENT_COLOR` и подберите свои.

**Проверка:** скорость букв меняется, а сюжетные данные остаются нетронутыми.

## Этап 4. Создаём узлы диалогов

Откройте `story/demo.json`. В нём есть:

- `start` — ID первой реплики;
- `nodes` — словарь всех реплик;
- `speaker` — имя говорящего;
- `text` — текст;
- `background` — имя изображения фона;
- `character` — имя изображения персонажа;
- `next` — ID следующей реплики;
- `choices` — список вариантов ответа.

Добавьте в `nodes` ещё один узел:

```json
"extra": {
  "speaker": "Система",
  "text": "Это новая реплика, добавленная учеником.",
  "background": "default",
  "character": "placeholder",
  "next": "question"
}
```

Затем измените у `intro` поле `next` с `"question"` на `"extra"`.

**Важно:** между соседними элементами JSON нужны запятые. Последний элемент списка или объекта не должен заканчиваться запятой.

**Проверка:** новая реплика появилась между вступлением и выбором.

## Этап 5. Делаем выбор и ветвления

В узле `question` найдите массив `choices`:

```json
"choices": [
  {"text": "Вариант А", "next": "ending_a"},
  {"text": "Вариант Б", "next": "ending_b"}
]
```

1. Измените названия кнопок.
2. Добавьте третью кнопку, ведущую на новый узел `ending_c`.
3. Создайте `ending_c` в словаре `nodes` (без `next` и `choices`).
4. Проверьте все три варианта.

**Подсказка:** при запуске `Story` проверяет, существуют ли все ID из переходов. Поэтому опечатку в `next` вы увидите сразу.

## Этап 6. Подключаем графику

1. Поместите изображение фона `room.png` в `assets/backgrounds/`.
2. Укажите `"background": "room"` у нужного узла.
3. Поместите `hero.png` с прозрачным фоном в `assets/characters/`.
4. Укажите `"character": "hero"`.
5. Перезапустите игру.

**Почему без расширения?** Функции в `Resources` сами добавляют `.png` к имени.

**Совет:** фон 1000×600, персонаж — PNG с прозрачным фоном. Фон масштабируется на весь экран, персонаж уменьшается при высоте более 470 пикселей. При отсутствии файла показывается заглушка.

## Этап 7. Исследуем появление текста

Найдите в `novel/app.py`:

```python
self.visible_chars = min(len(self.node.text), self.visible_chars + TEXT_SPEED * dt)
```

`dt` — время одного кадра в секундах. Так скорость текста почти не зависит от FPS.

**Задания:**

1. Уменьшите и увеличьте `TEXT_SPEED`.
2. Найдите метод `advance()`. Почему первый клик иногда не переключает реплику?
3. *Задание со звёздочкой:* по нажатию `Tab` включайте мгновенное отображение всех букв.

## Этап 8. Сохранение и загрузка

1. Дойдите до любой реплики и нажмите `S`.
2. Откройте `saves/save.json`. Посмотрите на поле `node_id`.
3. Перейдите дальше и нажмите `L`.
4. Убедитесь, что история вернулась к сохранённому узлу.

**Задание:** объясните, почему нельзя сохранять непосредственно объект `pygame.Surface` в JSON.

**Ограничение:** сохранение пока не помнит, сколько букв уже появилось.

## Этап 9. Добавляем возможность развития движка

Выберите одну задачу (реализовать самостоятельно):

**Уровень 1 — интерфейс**
- Кнопка «Скрыть диалог» на `H`.
- Изменение размера шрифта в одном месте.
- Индикатор текущего узла в режиме отладки.

**Уровень 2 — игровые функции**
- История прочитанных реплик.
- Музыка, которая меняется при переходе между узлами.
- Несколько слотов сохранений.

**Уровень 3 — архитектура**
- Словарь `variables` для флагов (`has_key`, `trust`).
- Условия отображения вариантов ответа.
- Отдельные экраны главного меню и настроек.

### Как правильно добавлять функцию

1. Определите, какие **данные** нужны. Например, `music` в JSON.
2. Решите, какой модуль отвечает за эти данные (формат истории — `story.py`).
3. Решите, кто выполняет действие (загрузка звука — `resources.py`, запуск — `app.py`).
4. Избегайте огромной функции, в которой одновременно читается JSON, рисуется кнопка и играет музыка.
5. Проверьте, что старые реплики и сохранение продолжают работать.

## Частые ошибки

**`ModuleNotFoundError: pygame`** — установите Pygame через `python -m pip install -r requirements.txt` в том же окружении, в котором запускаете проект.

**`FileNotFoundError`** — запускайте `run.py` из проекта, не переименовывайте `story/demo.json` без обновления пути в `settings.py`.

**`JSONDecodeError`** — проверьте двойные кавычки, запятые и парные скобки JSON.

**`ValueError: ... несуществующий ...`** — переход `next` ведёт на ID, которого нет в `nodes`.

**Не виден персонаж** — проверьте имя файла и поле `character`. Файл должен лежать в `assets/characters/`.

**Русский текст рисуется квадратиками** — установите системный шрифт с поддержкой кириллицы и укажите его в `novel/ui.py` вместо `arial`.
