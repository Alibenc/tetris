# Часть I. Изучаем модификаторы

## 1. Что такое модификатор?

**Модификатор (Modifier)** — операция, которая изменяет внешний вид или геометрию объекта автоматически, по выбранным параметрам. Например, делает копии, скругляет края, отражает половину модели или сглаживает форму.

Представь, что ты сделал один кирпич. Можно вручную дублировать его 30 раз, а можно добавить **Array**, который сам построит ряд кирпичей. Если изменить исходный кирпич, все копии обновятся.

### Чем модификатор отличается от Edit Mode?

- В **Edit Mode** ты меняешь исходную геометрию: передвигаешь вершины, выдавливаешь грани, создаёшь разрезы.
- **Модификатор** обычно работает **неразрушающе (non-destructive)**: исходная сетка остаётся прежней, а итоговая форма вычисляется автоматически.
- Модификатор можно временно выключить, настроить или удалить.
- Если нажать **Применить (Apply)**, вычисленный результат запишется в реальную геометрию. Отдельного модификатора больше не будет.

### Где искать модификаторы?

1. Выдели объект в **Объектном режиме (Object Mode)**.
2. Справа открой редактор **Свойства (Properties)**.
3. Нажми значок **гаечного ключа** — **Модификаторы (Modifiers)**.
4. Выбери **Добавить модификатор (Add Modifier)**.
5. В разделе **Генерация (Generate)** найди нужный модификатор.

Если значка ключа нет, проверь: выделен ли объект и открыт ли именно редактор **Свойства**.

### Почему порядок важен?

Модификаторы выполняются **сверху вниз**. Например:

- **Bevel → Array:** сначала скруглить исходный куб, затем создать копии;
- **Array → Bevel:** сначала создать копии, затем скруглить получившуюся геометрию.

Иногда результат выглядит одинаково, но при пересечениях и сложной сетке он различается. Порядок можно менять, перетаскивая модификаторы в списке.

**Запомни:** перед Bevel часто полезно применить масштаб объекта: в **Object Mode** нажать `Ctrl + A → Масштаб (Scale)`. Иначе скругления вытянутого объекта могут вести себя неожиданно.

### Быстрая проверка

1. Чем Apply отличается от кнопки выключения модификатора?
2. Почему в Edit Mode иногда виден только один куб, хотя на сцене десять?
3. Что произойдёт, если поменять форму исходной детали с Array?

## 2. Array — массив повторений

**Array** создаёт повторяющиеся копии по выбранным осям.

Основные настройки:

| Параметр | Значение |
|---|---|
| **Count (Количество)** | Сколько экземпляров будет **всего**, включая исходный. `4` означает 1 исходный + 3 дополнительных |
| **Relative Offset (Относительное смещение)** | Смещение относительно размера объекта по локальной оси |
| **X / Y / Z** | По какой оси располагаются копии |
| `1.0` | Обычно соседние экземпляры касаются друг друга, если форма и габариты позволяют |
| `1.1–1.2` | Между соседними экземплярами появляется небольшой промежуток |

### Мини-упражнение: ряд кирпичей

1. `Shift + A → Меш → Куб`.
2. В **Object Mode** сделай его вытянутым: `S → X → 1.5`, `S → Y → 0.5`, `S → Z → 0.35`.
3. Примени масштаб: `Ctrl + A → Масштаб`.
4. Добавь **Array** через значок ключа.
5. Установи `Count = 6`.
6. В **Relative Offset** выставь `X = 1.05`, `Y = 0`, `Z = 0`.
7. Получится ряд из шести кирпичей с небольшими зазорами.

**Задание со звёздочкой:** сделай полноценную кирпичную стену. Для этого дублируй ряд вверх, смести каждый второй ряд на половину кирпича, затем размножь чередующиеся ряды по Z вторым Array. В таком случае вертикальное смещение между одинаковыми рядами должно пропускать один промежуточный ряд.

![Пример: массив кирпичей](https://it-school-pro.ru/images/Pasted%20image%2020260305140432.png)

**Важно:** если применить Array, его копии станут реальной геометрией **одного меш-объекта**. Чтобы получить отдельные объекты из несоединённых частей, понадобится `P → По несвязанным частям (By Loose Parts)` в Edit Mode.

## 3. Bevel — скругление краёв

В реальности у вещей редко бывают идеально острые края. **Bevel** делает фаску или скругление.

### Мини-упражнение: скруглённая коробочка

1. Добавь куб.
2. Растяни его по X и чуть сплющи по Z.
3. В Object Mode нажми `Ctrl + A → Масштаб`.
4. Добавь модификатор **Bevel (Фаска)**.
5. Поставь **Amount (Ширина)** примерно `0.1`.
6. Поставь **Segments (Сегменты)** `3–5`.
7. Для ограничения по углу используй **Limit Method → Angle**, если эта настройка доступна в твоей версии Blender; угол около `30°`.

**Что изменилось?** Вместо одной жёсткой грани на углу появилось несколько маленьких граней, которые визуально дают плавное закругление.

### Инструмент и модификатор — не одно и то же

- `Ctrl + B` в **Edit Mode** — инструмент Bevel, который **сразу меняет** выбранные рёбра.
- **Bevel Modifier** — автоматическое скругление, настройки которого можно менять позже.

На клавиатуре мы будем применять оба способа.

---

## 4. Mirror — зеркальное отражение

**Mirror** создаёт зеркальную копию исходной геометрии относительно выбранной плоскости.

### Мини-упражнение: симметричная деталь

1. Добавь куб.
2. Перейди в Edit Mode и удали одну половину геометрии. Удобно сначала сделать центральный разрез `Ctrl + R`.
3. Вернись в Object Mode.
4. Добавь **Mirror**.
5. Проверь **Axis**: X, Y или Z. Оставь включённой ту ось, по которой модель должна отражаться.
6. Если половины должны соединяться по центру, включи **Clipping**, а при необходимости **Merge**.

**Важно:** без дополнительного объекта зеркало ориентируется на **локальные оси и начало координат (Origin)** исходного объекта. Поэтому положение Origin имеет значение.

**Mirror Object** позволяет назначить другой объект, относительно которого выполняется отражение.

### Самопроверка

Зачем Mirror удобнее ручного копирования, если ты моделируешь две симметричные части?

## 5. Solidify — толщина плоской поверхности

**Solidify** превращает плоскую поверхность в поверхность с толщиной.

### Мини-упражнение: тонкая панель

1. Добавь плоскость: `Shift + A → Меш → Плоскость (Plane)`.
2. Перейди в Object Mode, выбери **Solidify (Утолщение)**.
3. Установи **Thickness (Толщина)** примерно `0.15`.
4. Измени **Offset (Смещение)** и посмотри, в какую сторону появляется толщина.
5. Если геометрия сложная, проверь **Even Thickness (Равномерная толщина)**.

Solidify полезен для стенок, пластин, панелей и других изделий, которые изначально моделируются плоскими.

---

## 6. Subdivision Surface — сглаживание сетки

**Subdivision Surface (Подразделение поверхности)** увеличивает число граней и сглаживает форму. Его ещё называют **SubD**.

### Мини-упражнение: сглаживаем куб

1. Создай куб.
2. Добавь **Subdivision Surface**.
3. Установи **Levels Viewport (Уровни в окне просмотра) = 2**.
4. Посмотри: куб стал похож на округлую форму.
5. Перейди в Edit Mode и добавь разрез `Ctrl + R` рядом с одним из краёв.
6. Сдвинь разрез ближе к краю и посмотри, как изменилось сглаживание.

**Поддерживающие рёбра (support loops)** ограничивают сглаживание и помогают сохранить более чёткие углы.

![Поддерживающие рёбра](https://it-school-pro.ru/images/Pasted%20image%2020260213183239.png)

Обычно каждое следующее подразделение увеличивает число полигонов примерно в четыре раза. Поэтому не ставь уровни `8–10`: компьютер совсем не обязан переживать такие эксперименты. Для наших упражнений достаточно `1–3`, максимум `4`.

**Для клавиатуры SubD необязателен.** Основные формы проще получить с помощью Bevel.

## 7. Закрепление теории: гантель (дополнительно)

Попробуй объединить изученные модификаторы на одной модели.

1. Создай цилиндр и сформируй половину рукоятки.
2. Добавь **Mirror**, чтобы достроить симметричную вторую часть относительно центра рукоятки.
3. Добавь отдельный цилиндр для диска (блина) гантели.
4. Примени `Ctrl + A → Масштаб`, добавь **Bevel** с небольшим Amount.
5. При желании добавь **Subdivision Surface** с уровнем `1–2` и оцени форму.
6. Добавь **Array**, чтобы создать несколько дисков рядом по оси рукоятки.
7. Добавь **Mirror**, выбрав рукоятку как **Mirror Object**, чтобы получить такие же диски с другой стороны. Убедись, что центр и ось зеркала совпадают с осью гантели.

Это дополнительное упражнение. Если времени мало, переходи к клавиатуре.

# Часть II. Практика: создаём мини-клавиатуру

## 8. Подготовка проекта

1. Создай новый проект Blender: **Файл → Создать → Общий (General)**.
2. Выдели стартовые объекты и удали их: `A → X → Удалить`.
3. Сохрани сцену с именем `mini_keyboard.blend`.
4. Помни о клавишах управления:

| Клавиша | Действие |
|---|---|
| `Tab` | Object Mode / Edit Mode |
| `1 / 2 / 3` | В Edit Mode: вершины / рёбра / грани (верхний ряд цифр) |
| `G` | Перемещение |
| `S` | Масштаб |
| `E` | Выдавливание (Extrude) |
| `I` | Вставка грани (Inset) |
| `Ctrl + R` | Разрез (Loop Cut) |
| `Ctrl + B` | Фаска рёбер (Bevel) |
| `Shift + D` | Дублировать |
| `Ctrl + A` | Применить преобразования в Object Mode |
| `P` | Разделить меш в Edit Mode |

> Ориентация для этого самоучителя: **X — ширина клавиатуры (слева направо), Y — глубина (от переднего края к заднему), Z — высота**. Конкретные размеры условные и нужны лишь для удобства повторения.

## 9. Корпус клавиатуры

Начнём с основания, в которое будут установлены клавиши.

### 9.1. Делаем форму

1. В Object Mode: `Shift + A → Меш → Куб`.
2. Назови объект `Корпус` (выбери объект → `F2`).
3. Масштабируй: `S → X → 3.4`, `S → Y → 2.3`, `S → Z → 0.3`.
4. Подними: `G → Z → 0.35`. Корпус будет располагаться примерно над нулевой плоскостью.
5. Примени масштаб: `Ctrl + A → Масштаб (Scale)`.

Получился широкий невысокий прямоугольный корпус.

### 9.2. Скругляем углы в Edit Mode

1. Нажми `Tab`.
2. Переключись в выбор рёбер (`2`).
3. Сними выделение: `Alt + A`.
4. Выдели **четыре вертикальных угловых ребра** корпуса. Для нескольких рёбер удерживай `Shift`.
5. Нажми `Ctrl + B`, немного потяни мышью, затем введи примерно `0.3` и нажми `Enter`.
6. При необходимости до подтверждения прокрути колесо мыши для добавления сегментов. Для начала достаточно `4`.
7. Нажми `Tab`, чтобы вернуться в Object Mode.

**Проверка:** сверху корпус имеет закруглённые углы, а не острый прямоугольник.

### 9.3. Дополнительный Bevel на корпус

1. Справа открой **Свойства → Модификаторы** (значок ключа).
2. **Добавить модификатор → Генерация → Bevel**.
3. Пример настроек: **Amount = 0.05**, **Segments = 3**.
4. Если края слишком сильно скруглились, уменьши Amount.

Инструмент `Ctrl + B` создал основное закругление углов корпуса, а модификатор слегка смягчил остальные острые рёбра.

### 9.4. Делаем углубление для клавиш

В исходном уроке углубление создаётся через **Inset + Extrude**.

1. Перейди в Edit Mode (`Tab`).
2. Выбери грани (`3`).
3. Выдели верхнюю большую грань корпуса.
4. Нажми `I` и введи примерно `0.22` → `Enter`.
5. Нажми `E`, затем введи отрицательное значение, например `-0.08`, и подтверди `Enter`. Вдавливай грань внутрь по её нормали; если направление пошло наружу, используй противоположный знак.
6. Вернись в Object Mode.

**Проверка:** получилась неглубокая площадка внутри корпуса с рамкой по периметру. Если меш ведёт себя странно после скруглений, сначала убедись, что выбрана именно большая верхняя грань.

## 10. Три световых индикатора

Светящимися они станут позже, после настройки материалов. Сейчас сделаем лишь три маленьких круглых элемента на передней правой части корпуса.

1. `Shift + A → Меш → Цилиндр (Cylinder)`.
2. Уменьши его: `S → 0.07`.
3. Сплющи по Z: `S → Z → 0.35`.
4. Помести цилиндр на передний правый край корпуса (клавиша `G`, затем нужная ось `X`, `Y` или `Z`). Убедись, что он виден над поверхностью.
5. Назови объект `Индикаторы`.
6. Примени масштаб: `Ctrl + A → Масштаб`.
7. Добавь модификатор **Array**.
8. Установи `Count = 3`.
9. Поставь **Relative Offset** примерно `X = 2`, `Y = 0`, `Z = 0`. Если три цилиндра идут не вдоль нужного края, поменяй ось или знак смещения.
10. Подстрой расположение группы вдоль передней стороны корпуса.

**Проверка:** справа видны **три отдельных маленьких кружка**, между ними есть расстояние.

## 11. Моделируем одну клавишу

Сначала сделаем одну правильную клавишу, а затем размножим её массивами.

### 11.1. Форма клавиши

1. В Object Mode создай новый **Куб**.
2. Назови его `Клавиши`.
3. Сделай небольшой: `S → 0.42`, затем `S → Z → 0.7`. Эти значения примерные; клавиша должна быть заметно меньше корпуса.
4. В Edit Mode (`Tab`) включи выбор граней (`3`).
5. Перейди на вид снизу (`Ctrl + Numpad 7`) или поверни обзор так, чтобы видеть нижнюю грань.
6. Выдели **нижнюю грань** и немного увеличь её: `S → 1.15`.
7. Вернись в Object Mode и примени масштаб: `Ctrl + A → Масштаб`.

Теперь низ клавиши шире верха. Получилась форма, похожая на трапецию.

### 11.2. Небольшое углубление сверху

В исходном уроке для этого используются два центральных разреза.

1. Нажми `Tab` и перейди в выбор рёбер или вершин.
2. Сделай **один Loop Cut (`Ctrl + R`) вдоль верхней поверхности в направлении X**. Прокрути обзор и наведи курсор на нужное ребро, щёлкни, затем ПКМ, чтобы оставить разрез в центре.
3. Сделай **второй Loop Cut вдоль Y** таким же способом.
4. Перейди к вершинам (`1`).
5. На верхней поверхности найди центральную вершину, в которой пересекаются разрезы.
6. Выдели только её и слегка опусти: `G → Z → -0.035`.
7. Вернись в Object Mode.

**Проверка:** верхняя поверхность слегка вогнута. Не вдавливай вершину слишком сильно: клавиша не должна стать похожа на воронку.

### 11.3. Размещаем первую клавишу

1. Перемести клавишу к одному из углов внутренней площадки корпуса.
2. Подними по Z, чтобы низ клавиши немного заходил в углубление корпуса, но верхняя часть явно выступала наружу.
3. Сверху (`Numpad 7`) проверь, что внутри корпуса хватит места примерно на **4 клавиши по ширине и 4 по глубине**.

Если клавиша не подходит по размеру, подстрой её **до** создания массивов: это быстрее, чем исправлять десятки копий.

## 12. Создаём сетку из клавиш через Array

### 12.1. Первый Array: ряд

1. Выдели объект `Клавиши` в Object Mode.
2. Добавь **Array**.
3. Установи `Count = 4`.
4. В **Relative Offset** выставь `X = 1.15`, `Y = 0`, `Z = 0`.
5. Если копии пошли в неправильную сторону, поставь `X = -1.15` или перемести начальную клавишу к противоположному краю.

**Проверка:** виден ряд из четырёх кнопок с небольшими промежутками.

### 12.2. Второй Array: четыре ряда

1. На **том же объекте** добавь **второй Array**.
2. Поставь `Count = 4`.
3. В новом Array настрой `X = 0`, `Y = 1.15`, `Z = 0`.
4. При необходимости поменяй знак Y на отрицательный.
5. Подстрой размер исходной клавиши или величину смещения так, чтобы массив целиком помещался в корпус.

**Проверка:** получилась **сетка 4 × 4**, то есть 16 клавиш. Точные пропорции можно корректировать по референсу.

### 12.3. Скругляем клавиши

1. На объекте `Клавиши` добавь **Bevel**.
2. Ориентировочные настройки: `Amount = 0.035`, `Segments = 3`.
3. Если кнопки потеряли форму или скругление слишком сильное, уменьши Amount.

Порядок в списке модификаторов сейчас:

```text
Клавиши
├── Array      (4 по X)
├── Array      (4 по Y)
└── Bevel      (скругление)
```

Пока массивы не применены, в Edit Mode можно менять только **исходную клавишу**. Остальные выглядят как копии, но не являются независимыми объектами.

## 13. Превращаем копии в настоящие клавиши

Это важнейший этап. Нам нужно растянуть отдельные клавиши, но Array пока этого не позволяет.

### 13.1. Применяем два массива

1. Перейди в **Object Mode**.
2. Выдели объект `Клавиши`.
3. Справа открой вкладку **Модификаторы**.
4. У **первого (верхнего) Array** открой меню `▼` или `⋮` в заголовке модификатора и выбери **Применить (Apply)**. Вид меню зависит от версии Blender.
5. Затем таким же образом примени **второй Array**.
6. **Bevel пока можно оставить** как редактируемый модификатор.

**Важно:** модификаторы нужно применять в порядке **сверху вниз**. Перед Apply сохрани проект на всякий случай.

### 13.2. Разделяем сетку на отдельные объекты

1. Выдели `Клавиши` и перейди в Edit Mode (`Tab`).
2. Нажми `A`, чтобы выделить всю сетку.
3. Нажми `P → По несвязанным частям (By Loose Parts)`.
4. Вернись в Object Mode (`Tab`).
5. Щёлкни по одной из клавиш. Теперь должна выделяться **только она**, а не вся сетка.

После разделения Blender создаст несколько отдельных объектов. Они могут унаследовать Bevel, что нормально.

### 13.3. Исправляем Origin

**Origin** — оранжевая точка, относительно которой выполняются многие преобразования объекта. После разделения все клавиши могут получить Origin в месте исходной клавиши.

1. В Object Mode выдели **только клавиши**. Удобно выделить их в Outliner или изолировать перед операцией.
2. Нажми ПКМ по выделению.
3. Выбери **Установить начало координат (Set Origin) → Начало координат к геометрии (Origin to Geometry)**.

**Проверка:** оранжевая точка каждой клавиши находится примерно в её центре.

## 14. Делаем две длинные клавиши

На референсе есть две удлинённые кнопки: передняя большая клавиша и высокая клавиша справа. **Не нужно просто растягивать весь объект через `S`**, иначе закруглённые концы и форма боковин тоже растянутся.

### 14.1. Освобождаем место

1. Перейди на вид сверху (`Numpad 7`).
2. Посмотри на референс: одна длинная клавиша располагается у переднего края, другая — у правого края сетки.
3. Удали клавиши, которые должны уступить место длинным. Число удаляемых кнопок зависит от того, как ты разместил свою сетку.
4. Оставь **по одной** клавише-заготовке для каждой длинной кнопки.

В исходном уроке удаляемые клавиши показаны на скриншотах. Если у тебя их нет, руководствуйся здравым смыслом: на месте одной длинной кнопки не должно оставаться нескольких обычных.

### 14.2. Удлиняем клавишу через вершины

1. Выдели нужную клавишу.
2. Перейди в Edit Mode (`Tab`) и включи выбор вершин (`1`).
3. Если на клавише уже есть центральные Loop Cut, используй их как границы между центральной и крайней частями.
4. Перейди на вид сверху и включи рентген `Alt + Z`, чтобы видеть и выделять вершины с обратной стороны.
5. Рамкой (`B`) выдели **вершины одного конца клавиши вместе с ближайшей центральной линией**.
6. Перемести выделенное вдоль нужной оси (`G → X` или `G → Y`), удлиняя центральную часть.
7. При необходимости выдели только крайние вершины этого конца и сдвинь их ещё дальше, чтобы довести кнопку до желаемой длины.
8. Повтори для другой удлинённой клавиши, но уже в другой ориентации.

**Смысл метода:** мы увеличиваем расстояние между частями сетки, а не масштабируем сразу всю форму. Это помогает сохранить нормальные края и закругления.

**Проверка:** на корпусе есть обычные клавиши и две нестандартные, причём длинные выглядят естественно, без слишком широких фасок.

> Если вершины двигаются странно, убедись, что включён именно **Edit Mode**, а не Object Mode; выделены нужные вершины; ось перемещения соответствует направлению кнопки.

## 15. Кабель: учимся работать с кривыми

Для провода удобнее использовать **кривую Безье (Bezier Curve)**, а не цепочку кубов. Кривая позволяет рисовать плавные изгибы.

### 15.1. Создаём кривую

1. В Object Mode нажми `Shift + A → Кривая (Curve) → Безье (Bezier)`.
2. Назови её `Провод`.
3. Перейди в Edit Mode (`Tab`).
4. Выдели все контрольные точки (`A`) и удали: `X → Вершины (Vertices)`.
5. В левой панели инструментов (включается `T`) найди инструмент **Рисование (Draw)** для кривых. Его расположение зависит от версии Blender.
6. На виде сверху нарисуй плавную линию от заднего края клавиатуры в сторону.

Если **Draw** недоступен или неудобен, используй альтернативу: оставь исходную кривую Безье, перемести её две контрольные точки, затем выдели конечную и несколько раз нажми `E`, добавляя новые сегменты. Ручками контрольных точек регулируй изгибы.

### 15.2. Редактируем форму

- `G` двигает контрольную точку.
- `R` вращает ручки касательной, если они подходят для такого редактирования.
- `S` меняет расстояние между ручками (когда они выделены), а значит влияет на изгиб.
- `E` продолжает кривую от конечной точки.

Нарисуй провод с 2–4 мягкими поворотами. Не делай слишком много точек: простую кривую легче контролировать.

### 15.3. Придаём проводу толщину

1. Вернись в Object Mode.
2. Выдели кривую `Провод`.
3. Справа в Properties открой **Данные кривой (Curve Data)** — значок зелёной кривой.
4. Найди раздел **Геометрия (Geometry) → Фаска (Bevel)**.
5. Увеличь **Глубина (Depth)** примерно до `0.04–0.07`.
6. Если есть настройка **Resolution**, поставь `3–4`, чтобы сечение выглядело достаточно круглым.

**Проверка:** тонкая линия превратилась в объёмный круглый провод.

### 15.4. Поднимаем провод над основанием

1. Поверни сцену сбоку (`Numpad 3` или `Numpad 1`, в зависимости от направления).
2. Перемести кривую по Z так, чтобы провод не проходил сквозь основание.
3. В Edit Mode слегка приподними начальную точку провода, входящую в заднюю стенку клавиатуры.
4. Проверь вид сверху и перспективу: провод должен выглядеть как продолжение клавиатуры.

## 16. Плоскость под моделью

1. В Object Mode: `Shift + A → Меш → Плоскость (Plane)`.
2. Назови `Поверхность`.
3. Увеличь плоскость: `S → 10`.
4. Поставь её чуть ниже клавиатуры, чтобы корпус не проваливался и не пересекался с ней.
5. Посмотри на модель в перспективе (вращение средней кнопкой мыши).

Пока это просто геометрия. Материалы, фон, камеру, свет и красивый рендер мы сделаем на следующих занятиях.

## 18. Частые ошибки и решения

| Проблема | Что проверить |
|---|---|
| Bevel делает огромные или кривые скругления | Применён ли масштаб `Ctrl + A → Масштаб`? Не слишком ли большой Amount? |
| Array располагает копии вплотную или с громадными промежутками | Проверь Relative Offset и размеры **исходной** детали |
| Копии Array идут не в ту сторону | Проверь ось и знак смещения: `X/Y/Z`, положительный или отрицательный |
| `P → By Loose Parts` не даёт 16 объектов | Применены ли оба Array? Действительно ли сетки клавиш не соединены друг с другом? |
| Клавиша вращается вокруг чужой точки | ПКМ → **Set Origin → Origin to Geometry** |
| Inset / Extrude двигает не ту поверхность | В Edit Mode включи выбор граней (`3`) и проверь выделение |
| На клавишах не получается выделить вершины на задней стороне | Включи рентген `Alt + Z` |
| Bezier-кривая не видна как объёмный провод | Увеличь **Curve Data → Geometry → Bevel → Depth** |
| Нет инструмента Draw для кривой | Редактируй точки исходной кривой вручную с помощью `G` и `E` |
| Модель выглядит серой, не как на референсе | Это нормально: цвета и текстуры будут в следующих уроках |
