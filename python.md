# Python: подготовка к разработке игр на Pygame

**20 практических заданий с наводящими подсказками**

Цель: научиться программировать игровую логику на чистом Python, прежде чем переходить к Pygame.

## Уровень 1. Координаты и управление персонажем

### Задание 1. Движение персонажа

Есть персонаж с координатами `x = 5`, `y = 5`.

Пользователь вводит команду `w`, `a`, `s` или `d`. Изменяйте координаты персонажа в соответствии с направлением движения.

После каждого действия выводите новые координаты.

**Подсказки:**
1. Для координат достаточно двух переменных: `x` и `y`.
2. Используйте `while`, чтобы персонаж мог двигаться несколько раз.
3. Для каждой команды используйте условие `if` или `elif`.
4. При движении вправо увеличивается `x`, а при движении влево уменьшается. Для вертикального движения изменяется `y`.

### Задание 2. Границы игрового поля

Доработайте предыдущее задание.

Игровое поле имеет размер 10×10. Персонаж не должен выходить за границы поля, даже если пользователь пытается это сделать.

**Подсказки:**
1. Если координаты начинаются с нуля, допустимые значения — от 0 до 9 включительно.
2. Перед перемещением проверяйте, допустима ли новая координата.
3. Например, движение вправо возможно только тогда, когда `x < 9`.
4. Можно сначала вычислить предполагаемые координаты, а затем проверить их.

### Задание 3. Телепортация

Персонаж находится в случайной точке поля.

Пользователь вводит координаты телепортации. Если точка находится внутри игрового поля, персонаж перемещается туда. В противном случае выводится сообщение об ошибке.

**Подсказки:**
1. Для генерации случайных координат пригодится модуль `random`.
2. Используйте `random.randint()`.
3. Проверяйте обе координаты одновременно с помощью `and`.
4. Меняйте текущие координаты только после успешной проверки.

### Задание 4. Преследователь

Есть игрок и враг, у каждого свои координаты.

Враг должен автоматически делать один шаг в сторону игрока при каждом ходе. Если координаты совпали — игрок пойман.

Враг может изменять только одну координату за ход.

**Подсказки:**
1. Создайте четыре переменные: `player_x`, `player_y`, `enemy_x`, `enemy_y`.
2. Сравните горизонтальные координаты игрока и врага.
3. Если враг находится левее игрока, его `x` нужно увеличить на 1.
4. Если горизонтальные координаты уже совпадают, двигайтесь по вертикали.
5. После перемещения проверяйте совпадение обеих координат.

### Задание 5. Расстояние до цели

Игрок находится в точке `(x1, y1)`, а сокровище — в `(x2, y2)`.

Вычислите расстояние между ними по формуле:

```text
d = sqrt((x2 - x1)² + (y2 - y1)²)
```

Если расстояние меньше 3, программа сообщает, что сокровище рядом.

**Подсказки:**
1. Найдите разность координат по каждой оси.
2. Возведите обе разности в квадрат и сложите.
3. Для квадратного корня можно использовать `math.sqrt()` или степень `0.5`.
4. После вычисления расстояния проверьте его с помощью `if`.
