# Установка SFML 3 через CMake в Visual Studio (Windows)

> Инструкция для учеников. Подходит для Visual Studio 2019/2022 и более новых версий при наличии совместимых инструментов C++. Используем **SFML 3**, а не SFML 2.

## 1. Что потребуется

- Windows 10/11.
- Visual Studio с поддержкой C++.
- Интернет для первой загрузки SFML.
- Git (для скачивания SFML через CMake FetchContent).
- CMake **3.28 или новее**.

**Важно:** SFML 3 требует C++17. Не путайте **Visual Studio** и **Visual Studio Code** — это разные программы.

## 2. Установка компонентов Visual Studio

1. Запустите **Visual Studio Installer** (через меню «Пуск»).
2. Найдите установленную Visual Studio и нажмите **«Изменить»**.
3. Во вкладке **«Рабочие нагрузки»** отметьте **«Разработка классических приложений на C++»** (*Desktop development with C++*).
4. В компонентах проверьте наличие:
   - компилятора **MSVC C++ x64/x86 build tools**;
   - **C++ CMake tools for Windows**;
   - Windows SDK.
5. Нажмите **«Изменить» / «Установить»** и дождитесь завершения.

Если Visual Studio уже установлена, переустанавливать её целиком не нужно.

## 3. Проверьте CMake и Git

Откройте PowerShell или терминал Visual Studio и выполните:

```powershell
cmake --version
git --version
```

Для SFML 3 нужен CMake версии 3.28 или выше. Если команда не находится или версия слишком старая, обновите CMake: https://cmake.org/download/ . Git: https://git-scm.com/downloads/win . После установки перезапустите Visual Studio.

## 4. Скачайте готовый проект

1. Откройте официальный шаблон: https://github.com/SFML/cmake-sfml-project
2. Нажмите **Code → Download ZIP**.
3. Распакуйте ZIP, например в `C:\Projects\SFML-Lesson`.
4. Откройте папку. В ней должен находиться файл **`CMakeLists.txt`** и папка **`src`** с **`main.cpp`**.

**Не создавайте обычный «Пустой проект C++» (`.vcxproj`)** — мы открываем готовую папку с CMake.

## 5. Откройте проект в Visual Studio

1. Запустите **Visual Studio**.
2. Выберите **«Файл → Открыть → Папка»** (*File → Open → Folder*).
3. Укажите папку `SFML-Lesson`, в которой лежит `CMakeLists.txt`.
4. Дождитесь автоматической настройки CMake. При первом запуске CMake скачает и соберёт SFML — это может занять несколько минут.
5. В меню **«Вид → Вывод»** (*View → Output*) при необходимости проверьте сообщения CMake.

**Признак успеха:** настройка CMake завершается без ошибок, и проект доступен для сборки.

## 6. Добавьте тестовую программу

Откройте `src/main.cpp` и замените содержимое следующим кодом для **SFML 3**:

```cpp
#include <SFML/Graphics.hpp>

int main() {
    sf::RenderWindow window(
        sf::VideoMode({800, 600}),
        "My First SFML Game"
    );

    while (window.isOpen()) {
        while (const auto event = window.pollEvent()) {
            if (event->is<sf::Event::Closed>()) {
                window.close();
            }
        }

        window.clear(sf::Color(30, 30, 30));
        window.display();
    }

    return 0;
}
```

Сохраните файл (`Ctrl + S`).

## 7. Соберите и запустите

1. Выберите конфигурацию **x64-Debug** (или доступную x64-конфигурацию).
2. В меню **«Сборка»** выберите **«Собрать всё»** (*Build → Build All*).
3. В верхнем списке запуска выберите исполняемый файл проекта (название зависит от `CMakeLists.txt`), **не `ALL_BUILD`**.
4. Нажмите **F5** для запуска с отладкой или **Ctrl + F5** для запуска без отладки.

**Ожидаемый результат:** появится окно 800×600 с тёмным фоном. Оно должно закрываться нажатием на крестик.

### Альтернативная сборка через терминал

Из корня проекта (папки с `CMakeLists.txt`), в среде с доступным компилятором MSVC:

```powershell
cmake -S . -B build
cmake --build build --config Debug
```

Если команды из обычного PowerShell не находят компилятор, используйте **Developer PowerShell for VS** или сборку внутри Visual Studio. Терминальная папка `build` может отличаться от папки сборки, которую использует сама Visual Studio.

## 8. Частые ошибки

### `cmake` не найден

CMake не установлен или отсутствует в `PATH`. Проверьте компоненты Visual Studio или установите CMake отдельно и перезапустите терминал.

### `Git executable not found` / ошибка `FetchContent`

Установите Git и проверьте `git --version`. Убедитесь, что есть интернет и доступ к GitHub. При необходимости повторите настройку CMake.

### `No CMAKE_CXX_COMPILER could be found`

Не установлен компилятор C++. Через Visual Studio Installer добавьте нагрузку **«Разработка классических приложений на C++»** и MSVC.

### `CMake 3.28 or higher is required`

Обновите CMake до 3.28 или новее. Убедитесь, что Visual Studio использует обновлённую версию.

### Ошибки с `pollEvent()` или `sf::VideoMode`

Вероятно, код взят из учебника для SFML 2, а подключена SFML 3. Эти версии имеют различия API. Используйте пример из раздела 6.

### Ошибка при смене компилятора или версии Visual Studio

Очистите кэш CMake через меню **«Проект → Удалить кэш и перенастроить»** (название пункта может отличаться). Если собираете в терминале, удалите папку `build` и повторите настройку. Не переносите готовую папку сборки между разными компьютерами.

### Окно не появляется

Проверьте, что выбран именно исполняемый файл приложения и сборка прошла без ошибок. Посмотрите окно **«Вывод»**.

## 9. Как устанавливать на нескольких компьютерах

1. Один раз настройте проект на компьютере преподавателя.
2. Сохраните исходники: `CMakeLists.txt`, `src/` и другие файлы проекта.
3. Передайте ученикам эту папку (без `build`, `.vs` и других сгенерированных каталогов).
4. На каждом компьютере установите C++-компоненты Visual Studio, Git и подходящий CMake.
5. Откройте папку через **«Файл → Открыть → Папка»** и дождитесь первой сборки.

**Главная идея:** пути к библиотекам SFML и `.lib` вручную прописывать не нужно. CMake-шаблон использует `FetchContent` и собирает подходящую версию SFML на каждом компьютере.
