# 11 заданий по Python — от простого к сложному

## Лёгкие — 1–5

### 1. Чётное или нечётное
Пользователь вводит целое число. Программа должна определить, чётное оно или нечётное.

**Пример:** `17` → `Нечётное`

### 2. Самое большое число
Пользователь вводит три числа. Найди наибольшее из них, не используя `max()`.

**Пример:** `12, 45, 23` → `45`

### 3. Калькулятор скидок
Пользователь вводит стоимость товара. Если стоимость больше 5000 рублей, скидка составляет 15%, если больше 2000 — 10%, иначе скидки нет.

Выведи итоговую стоимость покупки.

### 4. Сумма цифр
Пользователь вводит положительное целое число. Программа должна посчитать сумму всех его цифр.

**Пример:** `5832` → `18`

**Усложнение:** решить без преобразования числа в строку.

### 5. Таблица умножения
Пользователь вводит число `n`. Выведи таблицу умножения для этого числа от 1 до 10.

**Пример:** `5 × 3 = 15`

## Средние — 6–10

### 6. Угадай число
Программа загадывает случайное число от 1 до 100. Пользователь пытается его угадать.

После каждой попытки программа сообщает: «Больше» или «Меньше». Когда число угадано, выводится количество попыток.

### 7. Проверка пароля
Пользователь вводит пароль. Он считается надёжным, если:

- Содержит минимум 8 символов.
- Содержит хотя бы одну цифру.
- Содержит хотя бы одну заглавную букву.
- Не содержит пробелов.

Программа должна сообщить, подходит ли пароль, а если нет — какие требования нарушены.

### 8. Второе по величине число
Пользователь вводит список чисел. Найди второе по величине **различное** число.

**Пример:** `[12, 45, 7, 45, 30]` → `30`

Нельзя использовать `sort()` и `sorted()`.

### 9. Анализ текста
Пользователь вводит предложение. Программа должна вывести:

- Количество слов.
- Самое длинное слово.
- Количество гласных букв.
- Количество уникальных слов без учёта регистра.

Знаки препинания не должны влиять на подсчёт слов.

### 10. Простые числа
Пользователь вводит число `n`. Программа выводит все простые числа от 2 до `n`.

**Пример:** `20` → `2, 3, 5, 7, 11, 13, 17, 19`

**Усложнение:** сделать проверку простоты отдельной функцией.

## Сложные — 11

### 11. Банкомат
Пользователь вводит сумму, которую хочет снять. Банкомат располагает купюрами номиналом 100, 500, 1000 и 5000 рублей.

Программа должна определить, какое минимальное количество купюр необходимо выдать.

**Пример:** `7600` → `5000 × 1, 1000 × 2, 500 × 1, 100 × 1`

Если сумму невозможно выдать, сообщить об ошибке.
