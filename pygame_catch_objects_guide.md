# Практическая работа: «Лови падающие предметы» на PyGame

**Уровень:** начинающий  
**Продолжительность:** 90–120 минут  
**Требования:** базовые знания Python (переменные, условия, циклы)  

## Цель занятия

Создать игру, в которой игрок управляет корзиной, ловит падающие яблоки и зарабатывает очки. За пропущенные яблоки снимаются жизни. В процессе вы научитесь создавать окно PyGame, рисовать фигуры, работать с координатами, обрабатывать клавиши, проверять столкновения и выводить текст.

> **Правило:** выполняйте шаги по порядку. После каждого изменения запускайте игру и проверяйте результат. Не копируйте всё сразу: старайтесь объяснить каждую новую строку.

## Этап 1. Установка PyGame и создание окна

Установите библиотеку в терминале:

```bash
pip install pygame
```

Создайте файл `main.py`:

```python
import pygame

pygame.init()

WIDTH = 800
HEIGHT = 600

screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Лови предметы")

running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((135, 206, 235))
    pygame.display.update()

pygame.quit()
```

**Разбор:**

- `pygame.init()` — инициализирует модули PyGame.
- `pygame.display.set_mode((WIDTH, HEIGHT))` — создаёт окно.
- `pygame.display.set_caption()` — устанавливает заголовок.
- `while running` — главный игровой цикл.
- `pygame.event.get()` — получает события, например закрытие окна.
- `screen.fill((R, G, B))` — закрашивает экран цветом RGB.
- `pygame.display.update()` — обновляет изображение.

## Этап 2. Рисуем игрока

В PyGame начало координат `(0, 0)` находится **в левом верхнем углу**. Ось X направлена вправо, ось Y — вниз.

Перед `while running` добавьте:

```python
player_width = 100
player_height = 30
player_x = 350
player_y = 540
```

Внутри игрового цикла, **после** `screen.fill(...)`, добавьте:

```python
pygame.draw.rect(
    screen,
    (0, 0, 255),
    (player_x, player_y, player_width, player_height)
)
```

`pygame.draw.rect()` принимает поверхность, цвет и прямоугольник в формате `(x, y, ширина, высота)`.

**Самостоятельное задание №2:** поменяйте цвет и размеры корзины. Рассчитайте координату X так, чтобы корзина располагалась точно по центру окна.

## Этап 3. Управление корзиной

Перед игровым циклом:

```python
player_speed = 7
```

Внутри цикла, **после обработки событий** и **до рисования корзины**:

```python
keys = pygame.key.get_pressed()

if keys[pygame.K_LEFT]:
    player_x -= player_speed

if keys[pygame.K_RIGHT]:
    player_x += player_speed
```

`pygame.key.get_pressed()` сообщает, какие клавиши удерживаются. `-=` уменьшает координату X, а `+=` увеличивает.

Чтобы корзина не выходила за границы окна, сразу после обработки клавиш добавьте:

```python
if player_x < 0:
    player_x = 0

if player_x > WIDTH - player_width:
    player_x = WIDTH - player_width
```

## Этап 4. Ограничиваем FPS

FPS — число кадров в секунду. Пока движение задаётся в пикселях за кадр, поэтому важно ограничить частоту кадров.

Перед игровым циклом:

```python
clock = pygame.time.Clock()
```

В самом конце игрового цикла, **после** `pygame.display.update()`:

```python
clock.tick(60)
```

Теперь программа старается не превышать 60 кадров в секунду. Позже можно изучить движение с учётом прошедшего времени (`delta time`), чтобы скорость не зависела от FPS.

## Этап 5. Падающее яблоко

В начало файла добавьте:

```python
import random
```

Перед игровым циклом:

```python
apple_radius = 20
apple_x = random.randint(apple_radius, WIDTH - apple_radius)
apple_y = -20
apple_speed = 5
```

`random.randint(a, b)` возвращает случайное целое число в диапазоне от `a` до `b` включительно.

Внутри игрового цикла, **до рисования объектов**, добавьте движение:

```python
apple_y += apple_speed
```

После очистки экрана нарисуйте яблоко:

```python
pygame.draw.circle(
    screen,
    (255, 0, 0),
    (apple_x, apple_y),
    apple_radius
)
```

`pygame.draw.circle()` принимает поверхность, цвет, координаты центра и радиус.

После перемещения яблока, **до рисования**, добавьте возвращение наверх:

```python
if apple_y > HEIGHT + apple_radius:
    apple_y = -apple_radius
    apple_x = random.randint(apple_radius, WIDTH - apple_radius)
```

**Самостоятельное задание №4:** перекрасьте яблоко в жёлтый, измените скорость падения, сделайте появление яблока у верхней границы экрана. Зачем здесь `random.randint()`?

## Этап 6. Проверяем столкновения

Класс `pygame.Rect` описывает прямоугольную область. Даже круглое яблоко для простоты будем проверять через прямоугольник вокруг него.

Внутри игрового цикла, **после изменения координат игрока и яблока**, создайте области:

```python
player_rect = pygame.Rect(
    player_x,
    player_y,
    player_width,
    player_height
)

apple_rect = pygame.Rect(
    apple_x - apple_radius,
    apple_y - apple_radius,
    apple_radius * 2,
    apple_radius * 2
)
```

Сразу после этого добавьте проверку:

```python
if player_rect.colliderect(apple_rect):
    apple_y = -apple_radius
    apple_x = random.randint(apple_radius, WIDTH - apple_radius)
```

`colliderect()` возвращает `True`, если прямоугольники пересекаются.

**Важно:** проверку столкновения разместите **перед** проверкой, не упало ли яблоко за нижнюю границу. Код рисования выполняйте после обновления координат.

**Самостоятельное задание №5:** объясните, почему из координат яблока вычитается радиус, а ширина и высота прямоугольника равны `apple_radius * 2`.

## Этап 7. Счёт

Перед игровым циклом:

```python
score = 0
```

Замените обработку столкновения на:

```python
if player_rect.colliderect(apple_rect):
    score += 1
    apple_y = -apple_radius
    apple_x = random.randint(apple_radius, WIDTH - apple_radius)
```

Перед игровым циклом создайте шрифт:

```python
font = pygame.font.SysFont("Arial", 32)
```

Внутри игрового цикла, **после рисования объектов и перед обновлением экрана**:

```python
score_text = font.render(
    f"Очки: {score}",
    True,
    (0, 0, 0)
)

screen.blit(score_text, (20, 20))
```

`font.render()` создаёт изображение с текстом, а `screen.blit()` выводит его на поверхность.

**Самостоятельное задание №6:** измените размер и цвет текста, перенесите счёт в правый верхний угол, начисляйте по 5 очков за яблоко.

## Этап 8. Жизни и проигрыш

Перед игровым циклом:

```python
lives = 3
```

Замените **старую** проверку падения яблока за экран на:

```python
if apple_y > HEIGHT + apple_radius:
    lives -= 1
    apple_y = -apple_radius
    apple_x = random.randint(apple_radius, WIDTH - apple_radius)
```

После вывода счёта добавьте:

```python
lives_text = font.render(
    f"Жизни: {lives}",
    True,
    (0, 0, 0)
)

screen.blit(lives_text, (20, 60))
```

Для экрана проигрыша в начале игрового цикла, **сразу после цикла `for event in pygame.event.get()`**, добавьте:

```python
if lives <= 0:
    screen.fill((30, 30, 30))

    game_over_text = font.render(
        "Игра окончена!",
        True,
        (255, 255, 255)
    )

    screen.blit(
        game_over_text,
        (WIDTH // 2 - 120, HEIGHT // 2)
    )

    pygame.display.update()
    clock.tick(60)
    continue
```

`continue` пропускает оставшуюся часть текущего прохода цикла. Поэтому после проигрыша игра перестаёт перемещать предметы, но окно продолжает работать.

**Самостоятельное задание №7:** сделайте 5 жизней и выведите итоговый счёт на экране проигрыша. Дополнительно попробуйте центрировать надпись точно через `game_over_text.get_rect(center=(WIDTH // 2, HEIGHT // 2))`.

## Этап 9. Увеличиваем сложность

Замените обработку столкновения на:

```python
if player_rect.colliderect(apple_rect):
    score += 1

    if score % 5 == 0:
        apple_speed += 1

    apple_y = -apple_radius
    apple_x = random.randint(apple_radius, WIDTH - apple_radius)
```

Оператор `%` вычисляет остаток от деления. Например, `10 % 5 == 0`, а `12 % 5 == 2`. Поэтому скорость увеличивается на 5, 10, 15 и следующих кратных пяти очках.

**Самостоятельное задание №8:** увеличивайте скорость каждые 3 очка, но не позволяйте ей превысить 12. Подсказка: используйте `and`.
